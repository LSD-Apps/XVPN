XVPN

A split-tunnel VPN client that just takes your .conf.

XVPN is a config client for Windows, Linux and Android. You import your own WireGuard, OpenVPN or Hysteria2 profile; the app connects to your server, sends rule-matched traffic direct, and sends the rest through your tunnel — then tells you why something failed when it does.

It ships no nodes, servers, subscriptions or accounts. Cryptography comes from sing-box. You bring a lawful config.

Path in four steps

  1. Run a lawful WireGuard / OpenVPN / Hysteria2 server you control (or use a profile your organisation issued). Server install lives in each protocol’s official docs — not here.
  2. Export a client config (.conf / .ovpn / Hysteria2 YAML).
  3. Install XVPN, import, connect.
  4. Confirm status: rates move; failures show local vs server vs rule.

What you get

  • Automatic split tunnelling — bundled domestic rule sets go direct; everything else uses your tunnel. No rules to write for the common case.
  • DNS that follows routing — dual resolvers, cross-checked so a bad answer is less likely to drive the wrong path.
  • Failure attribution — local network vs your server vs a rule miss need opposite fixes; the status card separates them.
  • Privacy by design — no accounts, analytics, ads, crash reporters, or backend. Privacy policy.
