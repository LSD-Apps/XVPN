## 一、产品定位（最重要）

XVPN 是**开源客户端工具**，不是 VPN 服务、不是代理运营商、也不是节点市场。

| 本项目做的 | 本项目不做的 |
| --- | --- |
| 解析用户自备的配置文件 | **不提供**节点、服务器、订阅、账号 |
| 生成分流与 DNS 决策、观测连接结果 | **不运营**任何面向用户的网络服务 |
| 调用上游开源内核（sing-box）完成隧道 | **不实现**密码学；加密来自上游内核 |
| 本地保存配置与学到的规则 | **不收集、不上报**个人数据（见 [`PRIVACY.md`](../PRIVACY.md)） |

**一句话：你自备合法可用的配置与服务器；本软件只是客户端。**

公开仓库：<https://github.com/LSD-Apps/XVPN>  
版权与署名：见 [`AUTHORS`](../AUTHORS)、[`NOTICE.md`](../NOTICE.md)、[`CITATION.cff`](../CITATION.cff)。
