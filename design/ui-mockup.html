XVPN 界面原型 v1 · 桌面端 + 移动端 · 静态稿

产品定位：导入一个 .conf，点一下连接，其他什么都不用管。 所有分流判断（国内直连 / 国外走隧道）由 App 内置的规则库自动完成，界面上不出现任何需要用户填写的规则、IP 段或路由表。

界面设计的核心不只是"一个开关"，而是让自动识别这件事变得可见可验证：用户能随时看到某个域名是被判为直连还是走代理、命中了哪条规则，从而在"某网站打不开"时立刻判断是分流判错还是节点问题。

需要你确认的 7 个设计假设

  1. 默认深色主题，暂不做浅色（工具类应用惯例，也省一半设计量）。
  2. 连接态用绿色、代理路径用紫色、直连路径用蓝色。分流记录靠这两色一眼区分。
  3. "分流模式"默认智能分流且不暴露给普通用户；是否要保留"全局代理 / 全局直连"给高级用户？（现稿在设置页里放）
  4. Windows 默认走"系统代理"接管，免管理员权限、开箱即用；TUN 模式作为可选项（需管理员，但能接管所有程序，包括不认系统代理的游戏）。
  5. 分流记录默认开启。它有隐私含义（会记录访问过的域名），是否需要默认关闭或只保留最近 N 条？
  6. 多配置管理：是否允许导入多个 .conf 并在侧栏切换？（现稿按"支持"设计）
  7. Android 是否需要"按应用分流"（指定某几个 App 走 / 不走代理）？这会显著增加界面复杂度，现稿未放入。
