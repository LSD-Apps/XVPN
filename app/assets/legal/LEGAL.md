## 一、产品定位（最重要）

幽门（仓库与可执行文件名：XVPN）是**开源客户端工具**，不是 VPN 服务、不是代理运营商、也不是节点市场。

| 本项目做的 | 本项目不做的 |
| --- | --- |
| 解析用户**自备**的配置文件 | **不提供**节点、服务器、订阅、账号 |
| 生成分流与 DNS 决策、观测连接结果 | **不运营**任何面向用户的网络接入服务 |
| 调用上游开源内核（sing-box）完成隧道 | **不实现**密码学；加密来自上游内核 |
| 本地保存配置与学到的规则 | **不收集、不上报**个人数据（见 [`PRIVACY.md`](../PRIVACY.md)） |
| 在 GitHub 上公开源码与构建产物 | **不**协助获取第三方接入、不维护节点清单 |

**一句话：你自备合法可用的配置与服务器；本软件只是客户端。**

公开仓库：<https://github.com/LSD-Apps/XVPN>

## 二、预期的合法用途

本软件按通用网络客户端设计，常见且通常无争议的用途包括：

- 连接**你自己管理**的服务器（家里的 NAS / 软路由、云主机、实验室机器）；
- 使用**雇主、学校或机构正式发放**的 VPN / 隧道配置，远程访问其内网；
- 在你有权管理的设备上做分流、DNS 一致性与故障归因方面的开发、测试与研究。

是否合法**完全取决于你所在地、服务器所在地的法律以及你对服务器的授权**。
本项目不审查、不担保、不背书任何第三方节点、订阅来源或具体用途。
